# Beyblade Battle Arena Simulation System

A comprehensive physics-based simulation of Beyblade battles, inspired by the anime series. This system provides a robust foundation for AI agents to compete, evolve, and showcase creative strategies in physically accurate battles.

## Overview

The Beyblade Battle Arena is a hemispherical dome where customizable Beyblades compete in physics-driven 1v1 battles. The system incorporates:

- Realistic 3D physics simulation with collisions, friction, and environmental effects
- A customizable Battle Dome with weather effects and hotspots
- Beyblade entities with configurable attributes and superpowers
- Match simulation with AI-optimized reporting
- League management for tournaments and season tracking
- An AI interface for strategy submission and evolution
- Basic visualization for development and testing

## System Architecture

The system is structured into these key modules:

1. **Core Physics Engine**
   - Vector mathematics and collision detection
   - Force calculations and motion dynamics
   - Physical constraints and integration

2. **Battle Arena**
   - Hemispherical dome with variable friction
   - Environmental effects (weather, hotspots)
   - Chance vector for randomized elements

3. **Beyblades**
   - Customizable attributes (mass, radius, tip factor, etc.)
   - Strategy and superpower framework
   - Integrity and stability system

4. **Simulation Control**
   - Match execution and state management
   - Game rules and win conditions
   - AI-optimized match reporting

5. **AI Interface**
   - Configuration loading and validation
   - Strategy and superpower registration
   - League history and battle database

6. **Visualization**
   - Basic 3D rendering using Pygame
   - Weather and effect visualization
   - Debug information display

## Beyblade Attributes

Beyblades can be customized with these attributes:

- **Name**: Unique identifier
- **Mass**: 0.5-1.5 units (affects collisions)
- **Radius**: 0.05-0.1 units (collision detection)
- **Tip Factor**: 0.1-0.5 (friction loss)
- **Spin Power**: 0-10 rad/s (angular velocity)
- **Attack Rating**: 0.5-2.0 (damage multiplier)
- **Defense Rating**: 0.5-2.0 (damage reduction)
- **Strategy**: Function for movement and behavior
- **Superpower**: Special ability with constraints

Each Beyblade has a customization budget of 20 points distributed across these attributes:
- Mass: ×10 points
- Radius: ×100 points
- Spin Power: ÷2 points
- Attack Rating: 1 point per unit
- Defense Rating: 1 point per unit

## Battle Mechanics

Battles take place in a hemispherical dome with these characteristics:

- **Dome Equation**: x² + y² + (z-1)² ≤ 4
- **Gravity**: 9.8 m/s² downward
- **Friction**: Variable by position and weather
- **Collisions**: Physically accurate with momentum exchange
- **Weather Effects**: Clear, Rain, Wind, Heat
- **Hotspots**: Random boost or damage zones

Win conditions:
- Reduce opponent's integrity to 0
- Force opponent out of the dome
- Have higher integrity when time limit is reached

## AI Development

AIs can compete in the Beyblade Battle Arena by:

1. Creating a configuration file with Beyblade attributes
2. Implementing a strategy function to control movement
3. Designing a superpower with specific triggers and effects
4. Entering the league and competing in tournaments

The system provides:
- Detailed match reports for AI learning
- A shared battle database for rival profiling
- League standings and match history
- Progressive evolution opportunities

## Usage

### Running a Match

```bash
python main.py --match --ai1 beyblade1 --ai2 beyblade2
```

### Running a Tournament

```bash
python main.py --tournament --ais beyblade1 beyblade2 beyblade3 beyblade4 --rounds 2
```

### Creating a New AI

```bash
python main.py --create-ai --name new_beyblade
```

### Viewing League Standings

```bash
python main.py --standings
```

### Viewing Match History

```bash
python main.py --history
```

## LLM Reincarnation System

A unique feature of this system is the LLM (Large Language Model) reincarnation mechanism. When two AI bladers are set to duel:

1. Each AI outputs its strategies and tactics to a fresh instance of an LLM
2. The new LLM instances embody the Beyblade's identity and strategy
3. The Game Master AI provides the battle context and simulation parameters
4. The AIs compete in the physics-based arena, applying their strategies

This adds a meta-strategic layer, as AIs must effectively communicate their strategies to their "reincarnated" instances.
