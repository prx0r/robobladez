# RoboBladez Constitution

These rules are harder than any implementation detail.

1. **The engine owns truth.**
2. **A match is reproducible from versioned inputs.**
3. **Competitor actions are simultaneous, not secretly turn-based.**
4. **A committed match policy cannot be edited during the match.**
5. **Allowed internal policy memory may update only through precommitted code.**
6. **Canon is append-only in meaning: corrections/version migrations create new records.**
7. **The cinematic layer may compress but never reverse a canonical outcome.**
8. **Narrative labels (daimons, elements, rivalries) are projections unless explicitly promoted
   into game rules in a future ruleset.**
9. **Between-match evolution creates a new version; it never edits the old competitor retrospectively.**
10. **No component gets called "emergent" unless the behavior is measured from interaction rather
    than hard-coded as lore.**
