# Research provenance

This pack was researched on 2026-08-13.

Primary authoritative sources were:
- official Lightricks GitHub repositories
- official LTX API documentation
- official LTX blog/prompting guides
- official LTX-2 paper

Community sources are explicitly separated as anecdotal.

Key factual status:
- LTX API currently advertises LTX-2.3 Fast/Pro.
- LTX-2.3 supports 16:9 and 9:16 up to 4K in the documented API support matrix.
- Fast supports longer 1080p durations than Pro in the current support matrix.
- Pro is required for audio-to-video, Retake, Extend, Reframe.
- first/last-frame image-to-video is documented for LTX-2.3.
- official ComfyUI-LTXVideo examples include two-stage generation, IC-LoRA control, motion tracking, HDR, LipDub, pixel spatial upscaling, and text-to-audio.
- official trainer documents T2V, I2V, video extension, V2V IC-LoRA, A2V, V2A, video in/outpainting, T2A, audio extension/inpainting, A2A IC-LoRA, AV2AV IC-LoRA, and full fine-tuning.
