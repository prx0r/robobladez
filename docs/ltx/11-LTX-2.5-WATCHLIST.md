# LTX-2.5 Watchlist

When an official LTX-2.5 release appears, verify these before migration:

1. Official GitHub tag/checkpoint exists
2. Official Hugging Face model card exists
3. License changes
4. VAE / latent-space compatibility with 2.3
5. Gemma/text-encoder compatibility
6. LoRA compatibility
7. IC-LoRA compatibility
8. Keyframe pipeline compatibility
9. Retake/Extend API model names
10. portrait/landscape resolutions
11. max duration / FPS
12. native audio changes
13. VRAM requirements
14. ComfyUI core/custom-node support
15. whether old workflow JSON loads unchanged
16. reproducibility/seed behavior
17. whether 2.3 LoRAs need conversion or retraining

Do not rename your internal renderer from `ltx23` to `ltx25` until these are verified.
Prefer a generic backend ID:

```text
renderer_family = "ltx"
renderer_version = "2.3"
checkpoint_digest = "..."
workflow_version = "..."
```
