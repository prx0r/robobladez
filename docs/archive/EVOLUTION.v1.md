# Evolution

## Principle

Do not manufacture emergence by making each agent internally exotic.

Prefer:

```text
simple interpretable policy
× heterogeneous bodies
× repeated interaction
× opponent modelling
× selection/adaptation
× persistent history
= emergent meta
```

## Three timescales

### Within a round
Policy state may update according to precommitted logic.

### Between rounds
The same policy code can use accumulated match memory.

### Between matches
A new policy/body version may be generated from the prior version + replay analysis.

## MVP

No RL is required.

Start with:

- hand-written policies
- parameter sweeps
- opponent statistics
- behavior phenotype metrics
- policy lineages

Then add:

1. evolutionary parameter search
2. imitation/offline learning
3. self-play / PSRO-like populations
4. RL only when the action/state complexity justifies it

## Daimon rule

The daimon is not a random class assignment.

```text
observed behavior
→ phenotype metrics
→ affinity history
→ stable patterns
→ named manifestation
```

It is a narrative projection of actual competitive phenotype.

## Signature moves

A signature should be *discovered* from recurring decisive event/action patterns, then named
and visualized. Do not pre-script a signature and pretend it emerged.
