# Audio Strategy

Current LTX platform documentation supports synchronized audio/video generation and audio-to-video workflows.

Best project use:

```text
LTX local shot audio:
- ambience
- Foley
- impacts
- environmental sound
- short dialogue when convenient

Final edit:
- canonical narration
- persistent character voices
- score
- full mix
```

This prevents every independently generated clip from inventing incompatible music/narration.

Use audio-to-video when:
- motion should follow dialogue
- motion should follow music/rhythm
- a voice performance is already canonical
