# Retake / Extend / Reframe

## Retake
Use when only a time interval is wrong.

```text
0–3 sec good
3–5 sec bad
5–8 sec good
↓
retake only 3–5 sec
```

Ideal future loop:

```text
render
↓
vision QA
↓
bad interval detected
↓
Retake
↓
QA again
```

## Extend
Use when a successful shot should continue rather than starting a new generation.

Good for:
- pursuits
- environment reveals
- establishing sequences
- intro/outro padding

## Reframe
Use to turn a successful master shot into:
- 16:9
- 9:16
- social variants

without requiring a full new generation.

This is especially valuable because both projects will likely generate horizontal masters and vertical derivatives.
