# LTX-2.5 Migration / Verification Checklist

Before locking any 2.5 production implementation, confirm directly from the official 2.5 page and linked docs:

- exact API model IDs
- available Fast/Pro or equivalent variants
- exact duration matrix
- exact FPS matrix
- exact resolutions
- aspect ratios
- native audio behavior
- first/last-frame support
- keyframe support
- Retake support
- Extend support
- Reframe support
- local checkpoint filenames
- text encoder compatibility
- VAE compatibility
- LoRA compatibility
- IC-LoRA compatibility
- ComfyUI workflow compatibility
- minimum VRAM
- recommended VRAM
- storage requirements
- licensing
- API pricing
- seed semantics
- reproducibility guarantees

Store all of these in renderer configuration, not project logic.
