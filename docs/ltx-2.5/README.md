## Important source discipline

The official LTX-2.5 model URL above is treated as the version anchor.

At packaging time, the searchable LTX documentation index still exposed LTX-2.3 as the main indexed production/open-source line. Therefore this pack distinguishes:

- **LTX-2.5 VERIFIED** — claims tied to an official 2.5 source when retrievable.
- **LTX PLATFORM VERIFIED** — generic current LTX API/workflow capabilities documented officially.
- **2.3 COMPATIBILITY BASELINE** — workflow/model details documented for 2.3 that are useful architectural references but must not be silently assumed identical in 2.5.

The integration design is renderer-agnostic so this distinction does not affect RoboBladez or Monstah core architecture.
