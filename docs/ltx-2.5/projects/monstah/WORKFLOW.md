# Monstah + LTX-2.5

## Core rule

LTX does not decide scientific truth.

```text
EVIDENCE
→ RECONSTRUCTION
→ EVENT / SCENARIO
→ SHOT SPEC
→ LTX
→ EPISTEMIC + VISUAL QA
```

## Shot routing

### Environment reconstruction
I2V from versioned environment reference.

### Species hero shot
I2V from versioned scientific reconstruction.

### Historical interaction
Use only after truth-policy validation.
Use stronger motion/keyframe control for important interactions.

### Counterfactual
Carry `COUNTERFACTUAL` all the way through metadata and publication.

### Deep Blue data stories
Do not force LTX everywhere.
Maps, graphs, depth plots, timelines, and evidence panels should remain deterministic graphics.
